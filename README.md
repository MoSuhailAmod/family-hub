# Family Hub

Family Hub is a self-hosted household dashboard designed to provide a central place for managing family schedules and, over time, other day-to-day household information.

The project is being built incrementally, starting with a family calendar and dashboard before expanding into additional household modules.

## Current Functionality

The current version includes:

- Family dashboard with today's and upcoming events
- Responsive family calendar
- Month, week, and agenda calendar views
- Family member filtering
- Recurring calendar events
- Multiple participants per event
- Calendar API for creating, reading, updating, and deleting events
- Responsive desktop and mobile layouts
- Persistent PostgreSQL storage

## Technology

Family Hub currently uses:

- Next.js
- React
- TypeScript
- PostgreSQL
- Drizzle ORM
- Docker / Docker Compose
- FullCalendar

## Current Development Status

The backend calendar functionality and initial user interface are operational.

Development is currently focused on making the calendar fully interactive, including:

- Adding events from the UI
- Editing existing events
- Deleting events
- Recurrence controls
- Improved event details and interaction

Detailed technical, infrastructure, database, and development documentation will be maintained separately.
